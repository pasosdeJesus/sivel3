## Description

Implement signature-based authentication for citizens accessing the pre-alert layer and performing actions on `sivel.xyz`. No sessions, no JWT, no cookies — each action that requires authorization is authenticated with a fresh wallet signature.

**Why signature-based:**
- No sessions to manage, expire, or hack
- No friction for users (they already have a wallet)
- Aligned with Web3 principles
- Each action is independently verifiable

**Actions requiring signature:**

| Action | Endpoint | Why signature needed |
|--------|----------|----------------------|
| View pre-alert layer | `GET /api/pre-alerts` | Access to sensitive information (pre-alerts) |
| View full pre-alert JSON | `GET /api/pre-alerts/:id` | Only buyer can see full details |
| Convert pre-alert to alert | `POST /api/pre-alerts/convert` | Off-chain action, no payment |
| Score alert (documenter) | `POST /api/pre-alerts/:id/score` | Requires documenter identity |

**Actions NOT requiring signature:**

| Action | Endpoint | Why no signature needed |
|--------|----------|-------------------------|
| Buy pre-alert | `POST /api/pre-alerts/:id/buy` | Payment transaction on-chain IS the signature |

## Implementation

### 1. Frontend: Signature Request

```typescript
// lib/useSignedRequest.ts
import { useSignMessage, useAccount } from 'wagmi';

export function useSignedRequest() {
  const { signMessageAsync } = useSignMessage();
  const { address } = useAccount();

  const signedFetch = async (url: string, options?: RequestInit) => {
    const timestamp = Date.now();
    const message = `${url}:${timestamp}:${address}`;
    
    const signature = await signMessageAsync({
      message: message,
    });

    const response = await fetch(url, {
      ...options,
      headers: {
        ...options?.headers,
        'X-Wallet': address!,
        'X-Signature': signature,
        'X-Timestamp': String(timestamp),
        'Content-Type': 'application/json',
      },
    });

    return response;
  };

  return { signedFetch };
}
```

### 2. Backend: Signature Verification Middleware

```typescript
// lib/verifySignature.ts
import { verifyMessage } from 'viem';

export async function verifySignature(
  wallet: string,
  signature: string,
  timestamp: string,
  url: string
): Promise<boolean> {
  // Anti-replay: 5 minute window
  const now = Date.now();
  if (Math.abs(now - parseInt(timestamp)) > 5 * 60 * 1000) {
    return false;
  }

  const message = `${url}:${timestamp}:${wallet}`;
  const recovered = await verifyMessage({
    address: wallet as `0x${string}`,
    message: message,
    signature: signature as `0x${string}`,
  });

  return recovered.toLowerCase() === wallet.toLowerCase();
}

// Middleware for endpoints
export async function withCitizenAuth(
  request: Request,
  handler: (wallet: string) => Promise<Response>
) {
  const wallet = request.headers.get('X-Wallet');
  const signature = request.headers.get('X-Signature');
  const timestamp = request.headers.get('X-Timestamp');
  const url = request.url;

  if (!wallet || !signature || !timestamp) {
    return new Response('Missing auth headers', { status: 401 });
  }

  const isValid = await verifySignature(wallet, signature, timestamp, url);
```

### 3. Endpoints Updated

#### `GET /api/pre-alerts` (view layer)

```typescript
export const GET = async (request: Request) => {
  return withCitizenAuth(request, async (wallet) => {
    // 1. Verify KYC with learn.tg
    const verified = await checkLearnTgVerification(wallet);
    if (!verified) {
      return new Response('User not verified in learn.tg', { status: 403 });
    }

    // 2. Return pre-alerts
    const preAlerts = await db.selectFrom('pre_alert')
      .where('status', '=', 'pending')
      .selectAll()
      .execute();

    return Response.json({ pre_alerts: preAlerts });
  });
};
```

#### `GET /api/pre-alerts/:id` (view full JSON)

```typescript
export const GET = async (request: Request, { params }: { params: { id: string } }) => {
  return withCitizenAuth(request, async (wallet) => {
    const preAlert = await db.selectFrom('pre_alert')
      .where('id', '=', parseInt(params.id))
      .selectAll()
      .executeTakeFirst();

    // Only buyer can see full JSON
    if (preAlert.buyer_wallet && preAlert.buyer_wallet !== wallet) {
      return Response.json({
        id: preAlert.id,
        status: preAlert.status,
        titulo: preAlert.json_data.titulo,
        source_urls: preAlert.source_urls,
        // No JSON data
      });
    }

    return Response.json(preAlert);
  });
};
```

## Acceptance Criteria

- [ ] `GET /api/pre-alerts` requires signature + learn.tg verification
- [ ] `GET /api/pre-alerts/:id` requires signature; shows full JSON only for buyer
- [ ] `POST /api/pre-alerts/convert` requires signature + buyer verification

- [ ] All signature requests include timestamp (anti-replay)
- [ ] No sessions, no cookies, no JWT tokens
- [ ] Frontend can request signature on-demand (not on wallet connect)
