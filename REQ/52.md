## Description

Replace the `DOCUMENTER_WALLETS` environment variable whitelist with on-chain `DOCUMENTER_ROLE` SBT verification via `PasosDeJesusCredentials.sol`. Currently the `queue` and `score` endpoints check a hardcoded list — future documenters should be verified by their Soulbound Token on Celo.

**Why deferred:**
- Current EIP-191 signature verification on the score endpoint provides cryptographic proof of documenter identity
- `DOCUMENTER_WALLETS` env var is operationally manageable for MVP with a small documenter pool
- On-chain SBT verification requires documenters to have been minted the `DOCUMENTER_ROLE` token first (admin action via `bin/m credentials:grant-minter`)

## Implementation

### 1. On-chain verification helper

```typescript
// lib/credentials.ts (extend existing)
import { createPublicClient, http, parseAbi } from 'viem'

const CREDENTIALS_ABI = parseAbi([
  'function balanceOf(address account, uint256 id) view returns (uint256)',
])

export async function hasDocumenterRole(wallet: string, chainId: string): Promise<boolean> {
  const tokenId = await resolveTokenId('Documenter', chainId) // from credential_metadata
  const client = createPublicClient({
    chain: getViemChain(chainId),
    transport: http(process.env.NEXT_PUBLIC_RPC_URL!),
  })
  const balance = await client.readContract({
    address: CREDENTIALS_ADDRESS,
    abi: CREDENTIALS_ABI,
    functionName: 'balanceOf',
    args: [wallet as `0x${string}`, BigInt(tokenId)],
  })
  return balance > 0n
}
```

### 2. Replace in queue and score endpoints

```typescript
// Replace:
if (!(await isDocumenter(body.documenter_wallet))) {
  return NextResponse.json({ error: 'DOCUMENTER_ROLE required' }, { status: 403 })
}

// With:
const hasRole = await hasDocumenterRole(body.documenter_wallet, NETWORK)
if (!hasRole) {
  return NextResponse.json({ error: 'DOCUMENTER_ROLE SBT required' }, { status: 403 })
}
```

### 3. Remove DOCUMENTER_WALLETS from .env

Once all documenters have their SBT minted, remove the env var.
