## Description

Update the `AGENT_ROLE` in `SIVeL3PreAlertMarket` (Mainnet) to use the wallet
that is actually verified in the ERC-8004 registry.

**Background:**
A temporary wallet was used during initial deployment of `SIVeL3PreAlertMarket`.
The correct wallet (`0x8C88169977c180f6380C01daAA9c7F31894c20dc`) is already
verified in ERC-8004 (token ID 9330). This inconsistency needs to be resolved.

**Current state:**
- ERC-8004 verified wallet: `0x8C88169977c180f6380C01daAA9c7F31894c20dc`
- `AGENT_ROLE` in `PreAlertMarket`: Temporary wallet (to be replaced)

**After update:**
- Both roles match, ensuring the agent's identity and operational wallet are
  aligned.

## Deployment

### Command (using cast)

```bash
# Change agent wallet
cast send 0x9aefBD59455efE0F7732638eF791f35F110ddB0c \
  "setAgentWallet(address)" \
  0x8C88169977c180f6380C01daAA9c7F31894c20dc \
  --private-key $ADMIN_PRIVATE_KEY \
  --rpc-url https://forno.celo.org

# Verify
cast call 0x9aefBD59455efE0F7732638eF791f35F110ddB0c \
  "getRoleMember(bytes32,uint256)" \
  $(cast keccak "AGENT_ROLE") 0 \
  --rpc-url https://forno.celo.org
```

### Alternative (using bin/m)

```bash
bin/m credentials:set-agent-wallet \
  --network celo \
  --address 0x8C88169977c180f6380C01daAA9c7F31894c20dc
```
