## Description

Replace the current "Convert" button in `PreAlertModal` with an editable JSON form
that allows citizens to enrich the pre-alert data before submitting it as a citizen alert.

## Requirements

- Display pre-alert `json_data` in an editable form
- Fields: `titulo`, `hechos`, `fecha`, `departamento`, `municipio`, and any custom fields
- Validate against `relato.schema.json` (using `ajv` on frontend)
- Show diff between original pre-alert and citizen changes
- Submit via `POST /api/pre-alerts/convert` with `enriched_json`
- Mobile-friendly layout

## Dependencies

- Requires #48 (`PreAlertModal` component)
- Requires `ajv` + `relato.schema.json` schema file

- Parent: #48 (MVP frontend)
- Related: #44 (API endpoints)
