# R-#17: R‑#17 Implement Credit System with SLEARN and multi‑token support

Implement a credit system for researchers and documenters, allowing them to purchase usage credits with **USDT** and **SLEARN**. The system is designed with a flexible multi‑token architecture to easily add **COPm** and other tokens in the future.

**Why credits?**
- Researchers need to access advanced features (reports, AI queries, case exports)
- Documenters receive a monthly stipend (4,000 credits) but may need extra
- Credits create a sustainable revenue stream for sivel.xyz

**Why SLEARN?**
- Already integrated in the Pasos de Jesús ecosystem (learn.tg)
- Documenters earn SLEARN through their work (via #47)
- Users with premium SBTs from learn.tg can use SLEARN directly

**Why multi‑token architecture?**
- COPm (Colombian stablecoin) is planned for future integration
- Flexibility to add other regional tokens or stablecoins
- Avoids hardcoding token logic in multiple places

## Credit System Overview

| Parameter | Value |
|-----------|-------|
| **Base price (USA)** | 1 credit = $0.01 USD |
| **Typical monthly consumption** | 1,500 credits → $15 USD |
| **Documenter stipend** | 4,000 credits/month (free) |
| **Unused credits** | Do not roll over (use it or lose it) |

### Pricing by Country (HDI‑based)

`price = base_price × (HDI_user / HDI_reference)`, where `HDI_reference = USA (0.921)`

| Country | HDI | Price per credit | 1,500 credits |
|---------|-----|------------------|---------------|
| USA | 0.921 | $0.0100 | $15.00 |
| Colombia | 0.752 | $0.0082 | $12.30 |
| Sierra Leone | 0.458 | $0.0050 | $7.50 |

**Country verification:** Via learn.tg (Sierra Leone) or Self Protocol (other countries). User must explicitly authorize sivel.xyz to read their verified country.

## API Endpoints

### 1. `GET /api/credits/balance`

Returns the current credit balance for the authenticated wallet.

**Response:**
```json
{
    "wallet": "0x...",
    "balance": 4200,
    "stipend_remaining": 3800,      // If documenter
    "expires_at": "2026-07-01T00:00:00Z"
}
```

### 2. `POST /api/credits/buy`

Purchases credits with USDT or SLEARN.

**Request:**
```json
{
    "wallet": "0x...",
    "amount": 1500,                  // Credits to buy
    "payment_token": "SLEARN"        // or "USDT"
}
```

**Flow:**
1. Verify wallet ownership (signature or session)
2. If payment_token is SLEARN:
   - Check user has premium SBT (via `PasosDeJesusCredentials`)
   - Calculate required SLEARN amount: `slearnAmount = amount * 0.01 * 22` (1 credit = $0.01, 22 SLEARN = $1)
3. If payment_token is USDT:
   - Calculate required USDT amount: `usdtAmount = amount * 0.01` (in USD)
4. Call `transferFrom` to receive payment
5. Add credits to user's balance
6. Record transaction in `credit_transaction`
7. Return updated balance

**Response:**
```json
{
    "success": true,
    "wallet": "0x...",
    "new_balance": 5700,
    "payment_token": "SLEARN",
    "payment_amount": 330,           // 1500 × $0.01 × 22 = 330 SLEARN
    "transaction_id": 42
}
```

### 3. `POST /api/credits/use`

Deducts credits for a feature usage.

**Request:**
```json
{
    "wallet": "0x...",
    "feature": "ai_query",
    "metadata": { "query_id": 123 }
}
```

**Response:**
```json
{
    "success": true,
    "wallet": "0x...",
    "new_balance": 5680,
    "credits_used": 20
}
```

### 4. `GET /api/credits/history`

Returns transaction history for the authenticated wallet.

**Query params:**
- `limit` (default 20)
- `offset` (default 0)
- `type` (optional: 'purchase', 'usage', 'stipend')

## SLEARN Integration

### Contract Interaction

```typescript
// lib/payments/slearn.ts
import { SLEARN_ADDRESS, CREDENTIAL_ADDRESS } from '../config';

const slearnAbi = [
  'function slearnToUSDT(uint256 slearnAmount) external view returns (uint256)',
  'function usdtToSLEARN(uint256 usdtAmount) external view returns (uint256)',
];

const credentialAbi = [
  'function balanceOf(address account, uint256 id) external view returns (uint256)',
  'function isPremiumCourse(uint256 tokenId) external view returns (bool)',
];

export async function getSlearnPrice(credits: number): Promise<number> {
  const usdtAmount = credits * 0.01 * 1_000_000; // credits × $0.01 × 6 decimals
  const result = await publicClient.readContract({
    address: SLEARN_ADDRESS,
    abi: slearnAbi,
    functionName: 'usdtToSLEARN',
    args: [usdtAmount],
  });
  return Number(result);
}

export async function verifyPremiumSBT(wallet: string): Promise<boolean> {
  // Check if user has at least one premium course SBT
  const nextId = await publicClient.readContract({
    address: CREDENTIAL_ADDRESS,
    abi: credentialAbi,
    functionName: 'nextTokenId',
  });
  
  for (let i = 1; i < Number(nextId); i++) {
    const isPremium = await publicClient.readContract({
      address: CREDENTIAL_ADDRESS,
      abi: credentialAbi,
      functionName: 'isPremiumCourse',
      args: [i],
    });
    if (isPremium) {
      const balance = await publicClient.readContract({
        address: CREDENTIAL_ADDRESS,
        abi: credentialAbi,
        functionName: 'balanceOf',
        args: [wallet, i],
      });
      if (Number(balance) > 0) return true;
    }
  }
  return false;
}
```

### Purchase with SLEARN

```typescript
// apps/nextjs/app/api/credits/buy/route.ts
export async function POST(request: Request) {
  const { wallet, amount, paymentToken } = await request.json();

  // Verify premium SBT for SLEARN
  if (paymentToken === 'SLEARN') {
    const hasPremium = await verifyPremiumSBT(wallet);
    if (!hasPremium) {
      return new Response('Premium SBT required for SLEARN payments', { status: 403 });
    }
  }

  // Calculate payment amount
  const paymentAmount = await calculatePayment(amount, paymentToken);

  // Transfer tokens
  await transferTokens(wallet, paymentToken, paymentAmount);

  // Add credits
  await addCredits(wallet, amount);

  return Response.json({ success: true, new_balance: balance });
}
```
