# R-#37: Batch Certification Contract for Validator Cases (Merkle Tree + Off-chain Signatures)

Implement a smart contract that allows the Banco de Datos del CINEP (as VALIDATOR_ROLE) to certify semestral batches of cases (published in Noche y Niebla) without executing on-chain transactions or paying gas. The contract uses Merkle trees for batch verification and off-chain signatures for validator approval.

**Key design:**
- PdJ proposes a batch (merkleRoot + caseIds)
- Validator (BD CINEP) reviews the batch off-chain and signs the merkleRoot
- PdJ submits the signature to the contract via `verifyBatch()`
- The contract verifies that the signature comes from VALIDATOR_ROLE and marks the batch as verified

**No on-chain transaction required from CINEP** – they only sign off-chain (free).

---

## Smart Contract: `CaseBatchRegistry.sol`

### Features

| Feature | Description |
| :--- | :--- |
| **Batch proposal** | `proposeBatch(merkleRoot, caseIds)` – called by DEFAULT_ADMIN_ROLE (PdJ) |
| **Batch verification** | `verifyBatch(batchId, signature)` – anyone can call, but signature must be from VALIDATOR_ROLE |
| **Case lookup** | `verifyCaseInBatch(caseId, hash, proof)` – verify a specific case is in a verified batch |
| **Batch rejection** | `rejectBatch(batchId)` – only VALIDATOR_ROLE (if CINEP finds errors) |
| **Event logging** | `BatchProposed`, `BatchVerified`, `BatchRejected` |

### Roles

| Role | Wallet | Permissions |
| :--- | :--- | :--- |
| `DEFAULT_ADMIN_ROLE` | PdJ  | Propose batches |
| `VALIDATOR_ROLE` | Banco de Datos del CINEP | Sign batches (off-chain), reject batches (on-chain if needed) |
