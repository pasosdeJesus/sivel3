## Resumen

`pnpm audit` reportó 22 vulnerabilidades (1 critical, 4 high, 16 moderate, 1 low).

### 1. vitest 2.1.9 → 3.2.7 (critical + vite + esbuild)

```diff
- "vitest": "^2.1.9",
- "@vitest/coverage-v8": "^2.1.9",
+ "vitest": "^3.2.6",
+ "@vitest/coverage-v8": "^3.2.6",
```

Eliminó el critical (GHSA-5xrq-8626-4rwp). Los test-utils de `m` pasan
156/156 con vitest 3.2.7. Ver REQ/32.md.

**Advertencia**: `@pasosdejesus/mpdj 0.1.0` declara `vitest@^2.1.9` como peer
dep → warning de peer no satisfecho. No bloquea tests. Pendiente actualizar en `m`.

### 2. `pnpm audit --fix` — overrides agregados

Se agregaron overrides para axios, ws, serialize-javascript, uuid, diff,
esbuild, vite.

### 3. Problema: override de vite jaló rolldown (nativo)

El override automático `"vite@<=6.4.2": ">=6.4.3"` dejó subir vite a **8.2.1**,
que usa `rolldown` (bundler Rust nativo). rolldown no tiene binarios para
OpenBSD → error:

```
Unsupported OS: openbsd, architecture: x64
Cannot find module '@rolldown/binding-wasm32-wasi'
```

### 4. Fix: pin vite a 6.4.3 (no 8.x)

```diff
- "vite@<=6.4.1": ">=6.4.2",
- "vite@<=6.4.2": ">=6.4.3",
+ "vite@<=6.4.1": "6.4.3",
+ "vite@<=6.4.2": "6.4.3",
```

vite 6.4.x usa esbuild/rollup (no rolldown), compatible con adJ/OpenBSD.
vite 7+ integra rolldown → inviable en OpenBSD por ahora.

## Notas importantes para adJ/OpenBSD

- **rolldown** (vite 7+/vitest 4) usa bindings nativos sin soporte OpenBSD.
  Si se necesita vite 7+, requiere el fallback WASM `@rolldown/binding-wasm32-wasi`.
- **vitest 3.2.7** funciona con vite 6.4.3 (esbuild/rollup), no rolldown.
- El override de vite debe **pin** a una versión 6.4.x, no `>=` que salta a 8.x.
