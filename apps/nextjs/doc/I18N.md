# Internationalization (i18n) Guide — SIVeL 3

> *"Then they said, 'Come, let us build ourselves a city... so that we may make
> a name for ourselves'"* (Genesis 11:4). Unlike Babel, we use multiple
> languages to bring clarity and documentation to the truth of the victims.

---

## 1. Routing and Language Detection

We use a **sub-path routing** strategy with a dynamic segment `[locale]`.

- **Middleware (`middleware.ts`):** Detects the user's preferred language via
  the `accept-language` header and redirects to the appropriate sub-path
  (e.g., `/` -> `/es/`). API routes (`/api/*`) and static assets are excluded.
- **Supported locales:** `en` (English) and `es` (Spanish). Any other locale
  in the URL returns 404 via `app/[locale]/layout.tsx`.

---

## 2. Translation API

This project uses `@pasosdejesus/m/i18n` for all translations. See the
[package documentation](../../node_modules/@pasosdejesus/m/dist/i18n/README.md)
for the full API reference.

### Key exports from `@pasosdejesus/m/i18n`

| Export | Purpose |
|--------|---------|
| `createTranslator(locale, translations, common?)` | Pure function — works in server & client |
| `TranslationSet` / `LocaleStrings` | TypeScript types |

### Project-specific files

| File | Purpose |
|------|---------|
| `lib/i18n/common.ts` | Shared translations for all components |
| `hooks/useTranslation.ts` | React hook wrapping `createTranslator` + `common` |

### Resolution order

1. `translations[locale]`
2. `translations['en']`
3. `common[locale]`
4. `common['en']`
5. The raw key

## 3. Usage

### Client component

```tsx
'use client'
import { useTranslation } from '@/hooks/useTranslation'

const localT = {
  en: { title: 'Hello' },
  es: { title: 'Hola' },
}

export function MyComponent() {
  const { t } = useTranslation(localT)
  return <h1>{t('title')}</h1>
}
```

### Server component

```tsx
import { createTranslator } from '@pasosdejesus/m/i18n'
import commonTranslations from '@/lib/i18n/common'

export default async function Page({ params }: { params: { locale: string } }) {
  const { locale } = await params
  const t = createTranslator(locale, localT, commonTranslations)
  return <h1>{t('title')}</h1>
}
```

### Adding a new string

1. **Local scope:** Add to the component's inline `localT` object (both `en` and `es`)
2. **Global scope:** Add to `lib/i18n/common.ts` (both `en` and `es`)
3. **Use** via `t('key')` — placeholders use `{{0}}`, `{{1}}`, etc.
